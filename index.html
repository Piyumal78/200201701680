Relational Database Tables

Simple overview of database schema defined in prompt:

departments

dept_id (PK), dept_name, dept_code

officers

officer_id (PK), emp_no, full_name, email, dept_id (FK), designation, role

venues

venue_id (PK), venue_name, capacity, location

trainers

trainer_id (PK), full_name, trainer_type, email, contact_no

training_programmes

program_id (PK), title, start_date, end_date, venue_id (FK), trainer_id (FK), max_participants, status

programme_quotas & nominations

programme_quotas: program_id, dept_id, allocated_quota
nominations: nomination_id (PK), program_id, officer_id, status
